# Brave-Goggles
Egyedi Brave Search Goggles keresési szűrők gyűjteménye gépészeti tervezéshez, CAD-modellezéshez, szoftverfejlesztéshez, ipari alkatrészkereséshez, üzleti kutatáshoz és általános internetes kereséshez. Célja a releváns szakmai források előtérbe helyezése és a keresési zaj csökkentése.

Fájlnév: 02-creo-cad.goggle: Elsősorban hivatalos dokumentációk, CAD-fórumok, modellezési technikák, parametrikus tervezés és Creo automatizálás.

Példakeresések:
- Creo config.pro options
- Creo J-Link API examples
- Creo advanced assembly constraints
- Creo drawing GD&T annotations
