# Brave-Goggles
Egyedi Brave Search Goggles keresési szűrők gyűjteménye gépészeti tervezéshez, CAD-modellezéshez, szoftverfejlesztéshez, ipari alkatrészkereséshez, üzleti kutatáshoz és általános internetes kereséshez. Célja a releváns szakmai források előtérbe helyezése és a keresési zaj csökkentése.


A szűrők összefoglalása
01 – Gépészeti tervezés	Műszaki számítások, tervezés
02 – PTC Creo és CAD	Modellezés, CAD-problémák
03 – Szoftverfejlesztés	Programozás, alkalmazások
04 – Ipari alkatrészek	Beszerzés, STEP-modellek
05 – Üzletfejlesztés	Ügyfélszerzés, vállalkozás
06 – Tudományos kutatás	Szabványok, publikációk
07 – Tiszta internet	Mindennapi keresés

Fájlnév: 01-mechanical-engineering.goggle: Gépészeti tervezés, műszaki méretezés, szilárdságtani számítások, gépelemek, anyagismeret, tűréstechnika és mérnöki problémamegoldás. Elsősorban szakmai fórumok, mérnöki kézikönyvek, gyártói műszaki dokumentációk és tervezési irányelvek előtérbe helyezése.

Példakeresések:
- Shaft diameter strength calculation
- Bearing selection and load calculation
- Bolted joint design calculation
- Welded steel frame design
- Mechanical fit and tolerance selection
- Gear design and dimensioning
- Material selection for machine components
- Sheet metal design guidelines
- Fatigue strength calculation
- Mechanical engineering design best practices


Fájlnév: 02-creo-cad.goggle: Elsősorban hivatalos dokumentációk, CAD-fórumok, modellezési technikák, parametrikus tervezés és Creo automatizálás.

Példakeresések:
- Creo config.pro options
- Creo J-Link API examples
- Creo advanced assembly constraints
- Creo drawing GD&T annotations


Fájlnév: 03-software-development.goggle: Saját alkalmazások, weboldalak, asztali programok, API-k, GitHub-projektek és automatizálási eszközök fejlesztéséhez.

Példakeresések:
- Python SQLite database architecture
- C# WPF modern UI
- GitHub Actions automatic release
- REST API authentication best practices


Fájlnév: 04-industrial-components.goggle: Ez különösen hasznos lehet a mindennapi gépészeti tervezési munkában. Gyártói katalógusok, műszaki adatlapok, STEP-modellek és szabványos gépelemek keresésére szolgál.

Példakeresések:
- Linear guide rail 20 mm STEP model
- Adjustable machine feet M16
- Pneumatic cylinder ISO 15552
- Aluminium profile 40x40 CAD
- Toggle clamp 2000 N


Fájlnév: 05-business.goggle: A mérnöki vállalkozás fejlesztéséhez, potenciális ügyfelek felkutatásához, piackutatáshoz és B2B értékesítéshez.

Példakeresések:
- Mechanical engineering outsourcing Germany
- Special purpose machine manufacturers Austria
- Freelance mechanical design engineer projects
- B2B engineering lead generation
- Sondermaschinenbau Unternehmen Bayern


Fájlnév: 06-scientific-research.goggle:Mérnöki kutatásokhoz, tudományos publikációkhoz, műszaki szabványokhoz és elméleti háttéranyagokhoz.

Példakeresések:
- Fatigue analysis welded steel structures
- ISO 2768 general tolerances
- ASME Y14.5 geometric tolerancing
- Finite element analysis bolted connections
- S355 steel fatigue strength


Fájlnév: 07-clean-web.goggle: Általános napi használatra. Ennél nem egy szakmai területet emelünk ki, hanem a zavaró és kevésbé hasznos találatokat szorítjuk háttérbe.

Példakeresések:
Mindennapi általános kereséseidhez is használhatod. Vásárláskor viszont érdemes kikapcsolni.
